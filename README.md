# LitePlay — Downloads

A lightweight video player for Windows that plays every format: MP4, MKV, HEVC, AV1 and more, from 720p to 4K.

## ⬇ [Download LitePlay-Setup.exe](LitePlay-Setup.exe?raw=true)

1. Download the file and double-click it.
2. Press **Install**. No admin rights are needed.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**. This appears because the installer isn't code-signed.

Requires Windows 10 or 11, 64-bit.

Playback is powered by [libmpv](https://mpv.io) and [FFmpeg](https://ffmpeg.org) (GPL/LGPL).
