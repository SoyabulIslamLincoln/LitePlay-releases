# LitePlay — Downloads

A lightweight video player for Windows and Mac that plays every format: MP4, MKV, HEVC, AV1 and more, from 720p to 4K.

## ⬇ Download

| System | File |
|---|---|
| **Windows** 10 / 11 (64-bit) | [LitePlay-Setup.exe](https://github.com/SoyabulIslamLincoln/LitePlay-releases/releases/latest/download/LitePlay-Setup.exe) |
| **Mac** with Apple Silicon (M1–M4) | [LitePlay-mac-apple-silicon.dmg](https://github.com/SoyabulIslamLincoln/LitePlay-releases/releases/latest/download/LitePlay-mac-apple-silicon.dmg) |
| **Mac** with Intel | [LitePlay-mac-intel.dmg](https://github.com/SoyabulIslamLincoln/LitePlay-releases/releases/latest/download/LitePlay-mac-intel.dmg) |

The Mac version requires macOS 15 (Sequoia) or newer.

### Windows
1. Download `LitePlay-Setup.exe` and double-click it.
2. Press **Install**. No admin rights are needed.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**. This appears because the installer isn't code-signed.

### Mac
1. Open the `.dmg` and drag **LitePlay** into **Applications**.
2. Open LitePlay. The first time, macOS will say it can't verify the app, because the app isn't notarized by Apple.
3. Go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. You only need to do this once.

Playback is powered by [libmpv](https://mpv.io) and [FFmpeg](https://ffmpeg.org) (GPL/LGPL).
